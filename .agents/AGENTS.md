# Project-Scoped Rules

- Chỉ commit và push code lên GitHub khi người dùng yêu cầu rõ ràng. Tuyệt đối không tự động commit hoặc push code sau các thay đổi trừ khi được ra lệnh trực tiếp.
- Tuyệt đối không tự ý chỉnh sửa, tạo mới hoặc sửa đổi code (không lập trình) trong dự án khi chưa có yêu cầu cụ thể từ người dùng.
